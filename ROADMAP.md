# Roadmap

## Follow-Up Actions

- Add a follow-up action checkbox for brief/prospect rows, covering cases where a prospect asks to be called back.
- Surface the follow-up state on brief lists and brief detail pages so these prospects are easier to find later.
- Include follow-up activity in sales/ops visibility alongside notes, contacted, and meeting-booked status.

## User Enablement & Documentation

- Maintain a user-facing portal guide for new sales and operations users.
- Add screenshots or short walkthrough clips for common workflows.
- Add example operating rhythms for SDRs, managers, and ops users.
- Add troubleshooting guidance for login, missing data, and stale browser sessions.
